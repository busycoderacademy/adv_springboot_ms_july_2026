Docker kafka commmands:
---------------------

See Running Containers
----------------------------
docker ps

You should see something like:
----------------------------
zookeeper
kafka
kafka-ui

Enter inside Kafka Container
----------------------------

docker exec -it kafka bash

Kafka CLI tools are located in:
/usr/bin


List Topics
------------
Check if Kafka is running correctly.

kafka-topics --bootstrap-server localhost:9092 --list

Create a Topic
------------------
Example topic: orders

kafka-topics --create --topic orders --bootstrap-server localhost:9092 --partitions 3 --replication-factor 1

Verify:
kafka-topics --bootstrap-server localhost:9092 --describe --topic orders

PartitionCount:3 ReplicationFactor:1
Leader: 1
Replicas: 1
Isr: 1


Produce Messages (Producer Test)
-------------------------
Run producer:

kafka-console-producer --broker-list localhost:9092 --topic orders

Now type messages:
----------------
order1
order2
order3

Consume Messages (Consumer Test)
------------------------------
kafka-console-consumer --bootstrap-server localhost:9092 --topic orders --from-beginning

View Consumer Groups
------------------------
kafka-consumer-groups --bootstrap-server localhost:9092 --list

Describe a group:
-----------------
kafka-consumer-groups --bootstrap-server localhost:9092 --describe --group console-consumer


Check Topic Partition Distribution
------------------------------------
kafka-topics --bootstrap-server localhost:9092 --describe --topic orders

Shows:
Topic: orders
Partition:0 Leader:1 Replicas:1 Isr:1
Partition:1 Leader:1 Replicas:1 Isr:1
Partition:2 Leader:1 Replicas:1 Isr:1

Watch Kafka Logs (Very Useful)
----------------
From host machine:

docker logs -f kafka

Bonus: Enter Zookeeper Container
--------------------------------
docker exec -it zookeeper bash

Check brokers registered:
---------------------------------
zookeeper-shell localhost:2181 ls /brokers/ids


Typical debugging flow:
------------------
docker compose up -d
docker exec -it kafka bash
kafka-topics --list
kafka-console-producer
kafka-console-consumer
docker logs kafka
